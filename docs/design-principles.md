# Design Principles

## Brand Adjectives
Nostalgic · Energetic · Playful · Premium · Cultural · Collectible-driven · Entertainment-driven · Modern

## Avoid
Generic SaaS gradients, random glass cards, generic purple neon, meaningless blobs and recognizable AI-site defaults.

Nostalgia should influence visual language without becoming cliché retro UX. Decorative or pixel typography may be used as an accent, but longer copy must remain highly readable.

## Reference-Driven Design
Use reference-driven design instead of designing from a blank model default. Different references may inform hierarchy, typography, motion, imagery or section treatment. Never clone another brand.

## Event Identity
Each NF event can have its own visual identity while sharing the underlying NF UX system. Event key art should inform palette, typography personality, motifs, imagery treatment and motion — but should not simply be enlarged into a webpage.

Use authentic NF media as social proof.

## Motion
Establish the static experience before adding animations.

## Evaluation
Judge designs on hierarchy, distinctiveness, conversion clarity, typography, spacing, imagery, accessibility, responsiveness and performance.

Avoid design choices whose main purpose is showing off technical capability.
