# Conversion

## Primary Conversion
Physical attendance.

## Leading Conversions
- event-page engagement
- free RSVP
- VIP purchase
- add to calendar
- directions
- event planning

## Default Event-Page Persuasion Sequence
Hero → Reasons to Attend → Real NF Social Proof → Current Event Experiences → Marketplace → Optional VIP → Plan Your Visit → FAQ → Final CTA.

## Free Events
- Primary CTA is the free ticket or RSVP.
- VIP is secondary.
- Never create uncertainty over whether general admission is free.
- Post-registration commitment matters — the RSVP is the start of the funnel, not the end.

## Friction to Remove
- unclear venue location
- dates and hours
- parking
- transit
- entrance information
- ticket requirements
- event-specific FAQ
