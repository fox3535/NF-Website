# Website Strategy

Nostalgia Fest is an attendance engine, not a brochure site. Every page exists to move someone closer to physically showing up.

## Audiences
- **Primary:** attendees.
- **Secondary:** returning attendees, vendors, sponsors and partners.

Main attendee interests include TCG, collectibles, nostalgia, toys, pop culture, entertainment and family-friendly experiences.

## Funnel
Discovery → Interest → Event Page → RSVP/Ticket → Commitment → Reminder → Planning/Directions → Physical Attendance.

Physical attendance is more important than raw free RSVP count. A large RSVP list that does not show up is a failure, not a success.

## Traffic and Landing Pages
Event-specific landing pages should have strong message match with the ads that drive traffic to them.

## Architecture
Current planned architecture includes Home, Events, individual Event pages, Vendors and About/Contact. Do not create unnecessary pages.

## Event Pages
Event pages should immediately communicate what, when, where, price and why someone should attend — above the fold, on mobile, without scrolling for the basics.
