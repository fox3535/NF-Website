# References

Real material for grounding Nostalgia Fest design work — not a place for generic stock or AI-generated filler.

## Structure

- **`nf-brand/`** — official Nostalgia Fest logos, event key art, campaign graphics, sponsor assets, and other brand material.
- **`nf-media/`** — real photos and video from previous Nostalgia Fest events.
- **`websites/`** — approved external website references, organized by the specific quality we want to study from each one (homepage, event pages, motion, typography, mobile).
- **`inspiration/`** — looser screenshots or visual ideas that are not approved design references.

## Rules

- External references (`websites/`, `inspiration/`) are inspiration only and must never be cloned.
- Do not treat previous-event media (`nf-media/`) as footage of a current event.
- Do not publish unconfirmed guests, attractions, sponsors, or event claims based on filenames or graphics alone.
- Prefer quality over quantity when selecting assets for the eventual website.
